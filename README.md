# BookwormCLI

Локальная читалка FB2, FB2 в ZIP и EPUB для Linux. Движок BookwormEngine верстает текст пропорциональным шрифтом и передаёт в Ghostty глифы на прозрачном холсте через Kitty Graphics. В режиме «Как в терминале» фон, включая прозрачность окна, остаётся родным, а цвет глифов считывается при запуске. Чтобы подхватить смену темы самого Ghostty, перезапустите читалку. Меню и нижняя строка — обычный текст терминала.

## Сборка и запуск

Расположите BookwormCLI и BookwormEngine рядом. Для сборки нужны Rust с Cargo (проверено на 1.99), системная библиотека OpenSSL libcrypto и каталог шрифтов движка. Cargo использует соседний пакет `../BookwormEngine/crates/core` с включённой возможностью `raster`.

```sh
git clone https://github.com/IanGor/bookworm-engine BookwormEngine
git clone https://github.com/IanGor/bookworm-cli BookwormCLI
```

```sh
cargo build --release --locked
./target/release/bookworm
./target/release/bookworm "$HOME/Книги/Мастер и Маргарита.fb2"
```

Первый запуск без аргументов открывает библиотеку. Нажмите **D**, введите путь, например `~/Книги`, и нажмите **Enter**. Читалка запомнит папку и покажет её книги вместе с книгами из подпапок. В списке видны название, автор и процент чтения. Недавно открытые книги идут первыми, а прочитанные переносятся в конец списка под отбивками с месяцем и годом завершения. Точные копии занимают одну строку. Книгу по указанному в командной строке пути можно читать и за пределами выбранной папки.

## Клавиши

Буквенные команды работают в латинской раскладке в обоих регистрах.

| Где | Клавиши | Действие |
| --- | --- | --- |
| Библиотека | ↑ / ↓, PgUp / PgDn, Home / End | Выбрать книгу |
| Библиотека | Enter | Начать или продолжить чтение |
| Библиотека | E, затем Y или Д | Снять пометку о прочтении и вернуть книгу в общий список |
| Библиотека | D, R, W | Сменить папку, обновить список, посмотреть пропущенные файлы |
| Книга | →, ↓, PgDn, пробел | Следующая страница или разворот |
| Книга | ←, ↑, PgUp | Предыдущая страница или разворот |
| Книга | T, ↑ / ↓, Enter | Выбрать раздел в боковом оглавлении или в отдельном списке на узком окне; Esc отменяет выбор |
| Книга | N, затем Enter | Открыть сноску с одной из видимых страниц |
| Сноска | ↑ / ↓, Esc | Пролистать длинную сноску, вернуться к книге |
| Книга | F | Выбрать встроенную или свою гарнитуру |
| Книга, библиотека | S | Открыть настройки. Enter переключает бионическое чтение или открывает выбранный пункт, Esc возвращает назад |
| Книга | G | Переключить бионическое чтение: начала слов выделяются более плотным начертанием, как в Android. Режим сохраняется между запусками |
| Книга, библиотека | Y | Открыть цветовые темы: ↑ / ↓ — выбор, Enter — применить, Esc — отменить |
| Книга | D | Отметить дефект вёрстки и подготовить промпт для Hermes |
| Выбор шрифта | D | Указать папку с TTF / OTF, затем выбрать гарнитуру из списка |
| Книга | + / − (клавиши `+`, `=`, `-`) | Изменить кегль на 2 пикселя в пределах 12–72 |
| Книга | V | Переключить одну страницу и автоматический разворот |
| Книга | E, затем Y или Д | Записать завершение, когда видна последняя страница |
| Книга | ?, B или Esc | Показать клавиши, вернуться в библиотеку |
| Книга / библиотека | Q | Выйти |
| Любой экран | Ctrl+C | Выйти, восстановив терминал |

На широком окне слева видно оглавление с текущей главой. При сужении боковая панель скрывается первой; T по-прежнему открывает список разделов. Короткие уголки обозначают разворот, а прогресс и клавиша помощи остаются внизу.

В теме «Как в терминале» (по умолчанию) читалка наследует цвета Ghostty. Другие темы меняют фон, текст страниц и сносок, оглавление, прогресс и меню сразу, не трогая настройки Ghostty и позицию чтения. Выбор сохраняется в `library.toml`.

- «Как в терминале» — цвета терминала.
- «Янтарь» — тёплая тёмная палитра.
- «Светлый янтарь» — кремовый фон и тёмно-коричневый текст для чтения при ярком свете.

### Сообщить о дефекте вёрстки

В книге нажмите **D**. Стрелки **← / →** двигают курсор по тексту, **↑ / ↓** — по строкам, **Home / End** — к краям строки. Первый **Enter** фиксирует начало. Переместите курсор к концу фрагмента и нажмите **Enter** ещё раз, чтобы открыть описание. **PgUp / PgDn** переключают страницы, в том числе за пределами текущего разворота, не сбрасывая выделение. Можно выделять и в обратную сторону. Напишите, что не так, и нажмите **Enter** для сохранения. **Esc** отменяет действие до сохранения; после выхода из режима вы возвращаетесь на прежнюю страницу.

Bookworm сохраняет Markdown-промпт в `~/.local/share/bookworm/reports/` (или `$XDG_DATA_HOME/bookworm/reports/`) и показывает команду `hermes chat --query-file '…'`. Клавиша **C** копирует команду через буфер терминала. В другом окне Ghostty нажмите **Ctrl+Shift+V**, затем **Enter**, чтобы запустить интерактивный чат. Если терминал запрещает запись в буфер, команда остаётся на экране; можно также передать файл промпта уже открытому Hermes. В отчёте есть абсолютный путь, контрольная сумма книги, обе границы выделения, выделенный текст (у длинного фрагмента сокращается середина) и параметры вёрстки. Читалка не запускает агента и не отправляет данные; при запуске Hermes текст промпта обрабатывается выбранной в нём моделью. Уточнения и результат проверки появятся в том же чате Hermes.

Ширина разворота зависит от выбранного кегля. По умолчанию это 24 пикселя. Две страницы появляются, когда каждой хватает ширины в 25 кеглей. Размер букв сохраняется при переключении режима. После изменения размеров окна, кегля или гарнитуры видимой остаётся страница, содержащая сохранённое место в тексте. Доступны PT Serif, PT Sans, Charis SIL и Literata. Начертания пользовательских шрифтов из выбранной папки группируются по гарнитуре. Лицензии встроенных шрифтов доступны через `bookworm --licenses`.

## Библиотека и история

База находится в `$XDG_DATA_HOME/bookworm/library.toml`. По умолчанию это `~/.local/share/bookworm/library.toml`. Библиотека перечитывает каталог при первом входе в список за сеанс, выборе папки и по клавише **R**. При перелистывании открытая книга остаётся в памяти. Исходные книги открываются только для чтения.

Каждая запись в `[books.…]` имеет ключ SHA-256 от содержимого файла. Переименование и перемещение сохраняют историю точной копии. Поля `source_title` и `source_author` содержат сведения из книги. Чтобы изменить подпись в библиотеке, закройте читалку и добавьте в таблицу нужной книги две строки перед вложенной таблицей `anchor`.

```toml
title_override = "Моё название"
author_override = "Имя автора"
```

Можно задать одно из полей. Чтобы вернуть исходное значение, удалите соответствующую строку. Пара `anchor.block` и `anchor.offset` хранит номер блока и смещение в символах. Поле `progress` показывает процент до конца видимой страницы или разворота. Поле `last_read` хранит время последнего чтения в UTC.

В массиве `completions` хранятся даты и время каждого подтверждённого завершения в UTC. Переход на последнюю страницу даёт 100%. Для записи в историю нажмите **E** и подтвердите действие. При перечитывании читалка спросит отдельно и добавит ещё одну дату. Если снять пометку о прочтении в библиотеке клавишей **E**, в записи появится `rereading = true`, книга вернётся в общий список с текущим процентом, а прошлые даты в `completions` сохранятся до следующего завершения. Для подсчёта завершений за месяц можно сгруппировать даты из массива по `ГГГГ-ММ`.

Сохранение публикует целый TOML атомарно. Читалка проверяет версию базы и снимок файла. Если другой экземпляр или редактор изменил файл, сохранение завершится с ошибкой. Проверьте содержимое базы и запустите программу заново. При ошибке разбора путь к базе выводится в терминал.

## Проверка

```sh
cargo fmt -p bookworm --check
cargo test --locked
cargo build --release --locked
```

Интеграционный тест использует Python 3.11+ из-за модуля стандартной библиотеки `tomllib`. Он запускает бинарник в Linux PTY, отвечает на запрос возможностей и размера окна, декодирует переданные PNG и проверяет восстановление терминала. Для работы самой читалки Python не требуется.

Для визуальной проверки в Ghostty откройте книгу, расширьте окно до разворота и снова сузьте. На широком экране **V** переключает разворот и одиночную страницу. После **Q** должен появиться исходный экран терминала с курсором.
