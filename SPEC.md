# BookwormCLI — договорённости по первой версии

## Согласовано

- Самостоятельная читалка для Linux/Omarchy, ориентир — Ghostty. Синхронизации с Android нет. Общий Rust-движок FB2/EPUB выносится в отдельный проект и используется обеими читалками. Вёрстку не заменяем моноширинным терминальным текстом. Отрисовываем только глифы, без отдельной подложки страницы. Интерфейс остаётся текстовым. По умолчанию фон и цвет берём из терминала; `Y` в книге и библиотеке открывает меню цветовых тем. `Enter` применяет палитру ко всей читалке и сохраняет её в `library.toml`. `Esc` закрывает меню без изменений. Переключение темы не меняет позицию чтения и настройки терминала.
- `bookworm ПУТЬ` открывает книгу сразу; `bookworm` без аргументов открывает библиотеку. Библиотека позволяет выбрать одну папку, запоминает её и показывает книги из неё и всех подпапок единым списком: название, автор, прогресс. Недавно читанные сверху. Читалка не импортирует, не перемещает и не правит файлы книг.
- При достаточной ширине окна — две последовательные страницы без уменьшения шрифта, иначе одна. На широком окне слева видно оглавление с текущей главой; T переводит фокус, Enter открывает раздел, Esc возвращает к чтению. При сужении окно сначала скрывает боковую панель (T открывает отдельный список), затем переходит на одну страницу. Разворот обозначен короткими уголками, без сплошной рамки и разделителя. Внизу — прогресс и подсказка `? Клавиши`. Можно вручную перейти к одной странице; при перевёрстке сохраняется место в тексте.
- В первой версии нужны оглавление, переход к сноскам, выбор шрифта, папка с собственными шрифтами и настройка размера шрифта.
- `D` в книге включает выделение текста. Два нажатия `Enter` фиксируют границы фрагмента, в том числе на разных страницах. Навигация в этом режиме не меняет позицию чтения. Отчёт с описанием, обеими границами и параметрами вёрстки сохраняется отдельно от библиотеки и книги. Передача локальному Hermes — явное действие читателя; уточнения и результат остаются в его интерактивном чате.
- Одна локальная текстовая база в домашней директории: сведения о книгах, возможность вручную поправить название и автора, позиция и процент чтения, время последнего чтения для сортировки, дата и время завершения для помесячной статистики. Ручные поправки имеют приоритет над метаданными из книги.

## Предлагаемые детали

- База — `~/.local/share/bookworm/library.toml` по умолчанию, с учётом `XDG_DATA_HOME`. Невалидный или изменённый снаружи файл нельзя молча затирать.
- Для первой версии править метаданные можно в самом текстовом файле; отдельный экран статистики не обязателен, данные доступны напрямую.
- Книгу связываем с прогрессом по содержимому файла, чтобы не сбрасывать его при перемещении или переименовании точной копии.
- Для собственных шрифтов начать с TTF и OTF. Вывод отрисованных движком страниц в Ghostty через Kitty Graphics требует проверки в живом терминале.

## Завершение книги

- На последней странице (или на развороте с ней) доступно действие «Завершить книгу». Только оно фиксирует дату и время завершения в базе. Открытие последней страницы, в том числе через оглавление, само по себе не меняет статистику.
- Подтверждённое перечитывание записывается отдельным завершением и не заменяет предыдущую дату.
